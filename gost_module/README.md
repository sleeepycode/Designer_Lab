# GOST Document Analyzer

Модуль анализа и исправления `.docx` документов по правилам оформления лабораторных работ.

## Возможности
- Чтение `.docx`
- Разбор абзацев, runs и секций
- Классификация блоков: титульник / заголовок / основной текст
- Проверка правил оформления
- Формирование замечаний и предлагаемых исправлений
- Применение исправлений к самому файлу
- История операций и откат последней правки
- Простой HTTP API на FastAPI

## Установка
```bash
pip install -r requirements.txt
```

## Запуск API
```bash
uvicorn app.main:app --reload
```

## Пример API
- `POST /analyze` — анализирует файл
- `POST /apply-fix` — применяет правку
- `POST /undo` — откатывает последнюю правку
- `GET /document/{document_id}/issues` — список замечаний
- `GET /document/{document_id}/download` — скачать исправленный файл

## Структура
- `app/models` — Pydantic-модели
- `app/parser` — парсер DOCX и классификатор
- `app/rules` — правила проверки
- `app/engine` — анализатор и движок правок
- `app/core` — конфиг и хранилище
- `app/api` — REST endpoints

## Ограничения MVP
- Поддерживается только `.docx`
- Номер страницы и сложный layout не считаются
- Титульный лист определяется эвристически
- Undo — по истории операций, а не через Word Track Changes
