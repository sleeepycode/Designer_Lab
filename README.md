# \# GOST Document Analyzer

# 

# Модуль анализа и исправления документов `.docx` по требованиям ГОСТ (для лабораторных работ).

# 

# \## Возможности

# 

# \- Анализ Word-документа (.docx)

# \- Проверка оформления:

# &#x20; - шрифт

# &#x20; - размер текста

# &#x20; - межстрочный интервал

# &#x20; - отступ первой строки

# &#x20; - выравнивание

# &#x20; - поля страницы

# &#x20; - титульный лист

# \- Генерация списка ошибок (issues)

# \- Генерация исправлений (fixes)

# \- Применение правок к документу

# \- Откат изменений (undo)

# \- Экспорт исправленного файла

# 

# \## Подход

# 

# В основе модуля лежит rule-based система (система правил).

# 

# Каждое правило:

# \- проверяет конкретный параметр оформления;

# \- формирует ошибку при нарушении;

# \- при необходимости предлагает исправление.

# 

# Важно:  

# Это не классический ML, так как:

# \- требования ГОСТ строго формализованы;

# \- проверка должна быть точной;

# \- результаты должны быть детерминированными.

# 

# \## Архитектура

# 

# Модуль состоит из следующих частей:

# 

# \- `parser` — разбор `.docx` и извлечение структуры

# \- `models` — внутренняя модель документа

# \- `rules` — набор правил проверки

# \- `engine` — анализ, применение правок, undo

# \- `api` — интерфейс взаимодействия (FastAPI)
